# Pastebin

メンバーボードは、raw の Pastebin URL からメンバー一覧を読み込みます。ペーストの書式は、ティアが有効かどうかによって異なります。

---

## ティア無効

1 行に 1 つずつ名前を書きます。それ以外は何も必要ありません。

```
CrZ
FriendOne
FriendTwo
FriendThree
```

各行がボード上の 1 エントリになり、すべての名前はデフォルトの名前テキスト色で表示されます。

---

## ティア有効

名前、カンマ、ティアの順で、1 行に 1 エントリずつ書きます。

```
name,tier
```

例:

```
CrZ,Gold
FriendOne,Silver
FriendTwo,Bronze
FriendThree,Gold
```

### ティアのルール

*   カンマの後に書くティアは、`MB_MembersBoard` スクリプトの `Tier Names` 配列の要素のいずれかと **完全に一致** している必要があります（大文字・小文字は区別されます）。
*   ティアを省略した場合（カンマなしで名前だけ）や、ティアが `Tier Names` のどの要素とも一致しない場合でも、名前はボードに表示されますが、色は **デフォルトの名前テキスト色** にフォールバックします。
*   デフォルトの名前テキスト色は `MB_ConfigUI` スクリプトで設定します。詳細は [UI 設定](./uiconfiguration.mdx) ページを参照してください。
