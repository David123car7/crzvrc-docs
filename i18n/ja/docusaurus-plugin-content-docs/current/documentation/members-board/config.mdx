# 設定

メンバーボードの主な設定はすべて、**プレハブの親 GameObject** 上にあります。シーンのヒエラルキーでそれを選択し、Inspector で `MB_MembersBoard` スクリプトを見つけてください。ここから、ボードのタイトル、任意のティア機能、そしてメンバー一覧を Pastebin から取得する方法を制御します。

このページで説明するすべてのフィールドは `MB_MembersBoard` スクリプトで定義されており、参照用に開くことができます。

---

## 一般設定

*   **`Board Tittle`**: ボード UI の上部にタイトルとして表示されるテキストです。
*   **`Tiers Enabled`**: ティア機能を切り替えます。有効にすると、メンバーボードは名前ごとに異なるティアを割り当てられるようになります。これは、たとえば複数のティアがある Patreon を運営していて、各メンバーをそのティア別に表示したい場合に便利です。名前とティアの実際の書き方については [Pastebin](./pastebin.mdx) ページで説明しています。

---

## ティア設定

これらのフィールドは **`Tiers Enabled`** が有効な場合にのみ使用されます。

*   **`Tier Names`**: 各ティアの名前を保持する配列です（例: `Bronze`、`Silver`、`Gold`）。
*   **`Tier Colors`**: 各ティアに関連付けられた色を保持する配列です。

`Tier Names` と `Tier Colors` は **並列配列** です。インデックス `0` のティアはインデックス `0` の色を使用し、インデックス `1` のティアはインデックス `1` の色を使用します。以降も同様です。両方の配列の長さが同じで、要素が対応していることを確認してください。

---

## メンバーの自動取得

メンバーの名前（およびそのティア）は実行時に Pastebin から取得されるため、VRChat ワールドを再アップロードすることなくボードを更新できます。

*   **`Paste Bin URL`**: ペーストの **raw** URL です。Pastebin でペーストを作成し、**Raw** ボタンをクリックして、ブラウザのアドレスバーから URL をコピーします（`https://pastebin.com/raw/...` のような形式になります）。その値をここに貼り付けてください。
