# UI 設定

メンバーボードの見た目の設定は、プレハブ内の 2 つの GameObject に分かれています。

*   **`_UI`** — `MB_MembersBoardUI` スクリプトを持ち、ボードのレイアウトとスクロール動作を制御します。
*   **`_configUI`** — `MB_ConfigUI` スクリプトを持ち、メンバーエントリを描画する際に使用されるデフォルトの色を制御します。

---

## レイアウト設定（MB_MembersBoardUI）

これらはレイアウトの設定です。**アセットに最初から付属しているプレハブとは異なるサイズのボードを作成する場合にのみ、変更してください。**

*   **`Max Rows`**: ボードが一度に表示する行の最大数です。これが自動スクロールを制御します。名前の数が `Max Rows` に収まらない場合、すべてのエントリが見えるようにボードが自動的にスクロールを開始します。
*   **`Row Height`**: 1 行の高さです。`memberCard` プレハブ（各プレイヤー名の表示に使われるプレハブ）の高さを変更した場合にのみ、新しいカードサイズにレイアウトを合わせるために変更してください。
*   **`Scroll Speed`**: 名前の数が `Max Rows` を超えたときに、ボードが自動スクロールする速さです。
*   **`Column Spacing`**: ボード上の列と列の間の水平方向の間隔です。

:::warning
アセットに付属しているプレハブでは、`Max Rows`、`Row Height`、`Column Spacing` を **変更しないでください**。これらは各プレハブに合わせてすでに調整されています。異なる寸法のボードが必要な場合は、プレハブを複製して新しいものを作成し、そちらで値を調整してください。
:::

## スタイル設定（MB_ConfigUI）

このスクリプトは、ボードの見た目のスタイルを保存します。パネル自体で使用される色や画像、および各メンバーカードの外観です。

### パネル設定

*   **`Background Color`**: ボードの背景パネルの色です。
*   **`Border Color`**: ボードの外枠の色です。
*   **`Tittle Color`**: ボードのタイトルテキストの色です。
*   **`Default Names Text Color`**: ティアの色が適用されない場合にメンバーの名前に使われる色です。つまり、ティアが無効な場合や、エントリのティアが欠けているか `Tier Names` 配列のどの名前とも一致しない場合です。ティアの照合方法については [Pastebin](./pastebin.mdx) ページを参照してください。
*   **`Background Image`**: ボードの背景として描画される任意のスプライトです。

### メンバーカード設定

これらは、各名前を表示する個々のカード（`memberCard`）の見た目を制御します。

*   **`Card Has Border`**: 有効にすると、各メンバーカードに枠線が描画されます。
*   **`Card Has Background`**: 有効にすると、各メンバーカードに背景の塗りつぶしが描画されます。
*   **`Card Background Color`**: メンバーカードの塗りつぶしの色です。`Card Has Background` が有効な場合にのみ使用されます。
*   **`Card Border Color`**: メンバーカードの枠線の色です。`Card Has Border` が有効な場合にのみ使用されます。
