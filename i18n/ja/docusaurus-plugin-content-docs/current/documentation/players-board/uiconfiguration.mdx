# UI 設定

プレイヤーボードの見た目の設定は、プレハブ内の 2 つの GameObject に分かれています。

*   **`_UI`** — `PL_PlayersBoardUI` スクリプトを持ち、ボードのレイアウトとスクロール動作を制御します。
*   **`_configUI`** — `PL_ConfigUI` スクリプトを持ち、プレイヤーエントリを描画する際に使用されるデフォルトの色を制御します。

---

## レイアウト設定（PL_PlayersBoardUI）

これらはレイアウトの設定です。**アセットに最初から付属しているプレハブとは異なるサイズのボードを作成する場合にのみ、変更してください。**

*   **`Max Rows`**: 1 列あたり「満杯」とみなす行数です。ボードは **すべて** の列が満杯になって初めて自動スクロールを開始するため、この値を大きくすると、スクロールが始まる前により多くのプレイヤーを表示できます。
*   **`Row Height`**: 1 行の高さです。`playerCard` プレハブ（各プレイヤー名の表示に使われるプレハブ）の高さを変更した場合にのみ、新しいカードサイズにレイアウトを合わせるために変更してください。
*   **`Scroll Speed`**: すべての列が満杯になったときに、ボードが自動スクロールする速さです（UI 単位／秒）。
*   **`Column Spacing`**: 各列の Vertical Layout Group に適用される、行と行の間隔です。

:::warning
アセットに付属しているプレハブでは、`Max Rows`、`Row Height`、`Column Spacing` を **変更しないでください**。これらは各プレハブに合わせてすでに調整されています。異なる寸法のボードが必要な場合は、プレハブを複製して新しいものを作成し、そちらで値を調整してください。
:::

## スタイル設定（PL_ConfigUI）

このスクリプトは、ボードの見た目のスタイルを保存します。パネル自体で使用される色や画像、および各プレイヤーカードの外観です。

### パネル設定

*   **`Background Color`**: ボードの背景パネルの色です。
*   **`Border Color`**: ボードの外枠の色です。
*   **`Tittle Color`**: ボードのタイトルテキストの色です。
*   **`Names Text Color`**: ボード上のすべてのプレイヤー名に使われる色です。
*   **`Background Image`**: ボードの背景として描画される任意のスプライトです。

### プレイヤーカード設定

これらは、各名前を表示する個々のカード（`playerCard`）の見た目を制御します。

*   **`Card Has Border`**: 有効にすると、各プレイヤーカードに枠線が描画されます。
*   **`Card Has Background`**: 有効にすると、各プレイヤーカードに背景の塗りつぶしが描画されます。
*   **`Card Background Color`**: プレイヤーカードの塗りつぶしの色です。`Card Has Background` が有効な場合にのみ使用されます。
*   **`Card Border Color`**: プレイヤーカードの枠線の色です。`Card Has Border` が有効な場合にのみ使用されます。
