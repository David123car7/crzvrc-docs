# 設定

プレイヤーボードの主な設定は、**プレハブの親 GameObject** 上にあります。シーンのヒエラルキーでそれを選択し、Inspector で `PL_PlayersBoard` スクリプトを見つけてください。

---

## 一般設定

*   **`Board Tittle`**: ボード UI の上部にタイトルとして表示されるテキストです。

---

## プレイヤー数の上限（`PL_Config`）

ボードはワールドの読み込み時に、固定数のプレイヤースロットを確保します。その数値は `PL_Config` スクリプト内の `instancePlayerLimit` 定数です。

*   **`instancePlayerLimit`**（デフォルト: `80`）: ボードが表示できるプレイヤーの最大数です。Inspector には **公開されていません** — `PL_Config` スクリプトを開き、ファイル内で直接値を変更してください。

この値は、ワールドの最大インスタンス収容数に合わせて設定してください。そうすることで、同時に存在しうるすべてのプレイヤー分のスロットがボードに確保されます。
