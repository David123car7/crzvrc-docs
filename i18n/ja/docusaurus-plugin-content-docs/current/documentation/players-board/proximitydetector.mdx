# 近接検知（Proximity Detector）

プレイヤーボードのプレハブには、`CrZ_ProximityActivator` スクリプトが付いた **`ProximityDetector`** という子 GameObject が含まれています。スクリプト自体については [CrZ Utils](../crz-utils/crz-proximity-activator.mdx) ページで説明しています。

## 役割

近接検知は、**ボードがいつ自動スクロールするか** を制御します。

*   ローカルプレイヤーが検知エリアの **内側** にいるとき、ボードの UI が自動スクロールします（ボードに収まりきらない数のプレイヤーがいる場合）。
*   プレイヤーが **外側** にいるとき、自動スクロールは停止します。ボードは遠くからでも問題なく見えますが、静止したままになります。

これはパフォーマンスのための最適化です。スクロールするレイアウトは、実際に読める距離まで誰かが近づいているときにのみ更新されます。

## 範囲の調整

検知エリアは `ProximityDetector` GameObject 上の **Box Collider** です。自動スクロールを有効にしたい範囲に合わせて、このコライダーのサイズと位置を調整してください。ローカルプレイヤーがコライダーに入るとすぐにスクロールが有効になり、出ると停止します。

ボックスのサイズを決める際は、プレイヤーの中心付近だけを覆う薄い帯ではなく、**全身**（足元から頭の上まで）を覆うようにしてください。コライダーの縦方向が短すぎると、VRChat がプレイヤーの侵入を認識できず、スクロールが開始しないことがあります。
