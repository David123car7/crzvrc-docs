# 設定

Bouncer System は、Unity の Inspector から直接、高度にカスタマイズできます。メインの Bouncer System プレハブの設定を調整することで、プレイヤーにアクセスが許可または拒否されたときのシステムの反応を正確に調整できます。

以下は、利用可能なすべての設定オプションの完全な一覧です。

---

## コアとなる Bouncer トグル

これらの設定は、セキュリティ環境の基本的な動作とデフォルトの状態を決定します。

*   **`Fetch Security Names`**: 有効にすると、システムは権限を持つセキュリティ担当者のリストを、オンライン URL（raw な Pastebin リンクなど）から動的に取得します。これにより、VRChat ワールドを再アップロードすることなく、セキュリティスタッフをリモートで更新できます！ 無効にした場合は、Unity の Inspector にセキュリティ担当者の名前を直接手動で入力する必要があります。
*   **`Is Security On`**: このネットワーク同期（UdonSynced）される設定は、ワールドの新しいインスタンスが生成されたときのシステムのデフォルト状態を決定します。有効にすると、ワールド作成と同時に Bouncer System がすぐにアクティブになります。無効にすると、セキュリティメンバーがオンにするまでオフラインの状態で開始します。
*   **`Instance Owner Is Security`**: 有効にすると、インスタンスを作成したプレイヤー（インスタンスオーナー）は、名前がセキュリティリストに含まれているかどうかに関係なく、自動的に Security ロールが付与されます。

---

## フィードバックとインターフェース

システムがワールド内のプレイヤーにアクセスの変更をどのように伝えるかを設定します。

*   **`Security Animation`**: 有効にすると、ユーザーがアクセスを取得または喪失するたびに、システムは特定のアニメーションを再生します。物理的な「セキュリティゲート」や bouncer システムとしてこのシステムを使用している場合は、プレイヤーに明確な視覚的フィードバックを提供するため、これを強く推奨します。
*   **`Enable Notifications`**: 有効にすると、Bouncer System はアクセスの変更時に画面上のアラートを自動的にトリガーします。

:::info 
**Enable Notifications** 機能は、**CrZVRC Notification System** アセットもインストールされている場合にのみ動作します。
:::

## テレポートと移動

現在のアクセスレベルに基づいて、プレイヤーをワールド内で物理的に移動させるようにシステムを設定できます。

*   **`Teleport When Verified`**: 有効にすると、プレイヤーはアクセスが許可された瞬間に、特定の場所へ即座にテレポートされます。
*   **`Verified Position`**: `Teleport When Verified` が有効な場合にプレイヤーが送られる正確な Transform（座標と回転）。
*   **`Teleport When Unverified`**: 有効にすると、セキュリティメンバーによってアクセスが取り消された際に、プレイヤーは即座に離れた場所へテレポートされます。
*   **`Reset Position`**: フォールバックまたは「キックされた」場所を表す Transform（座標と回転）。アクセスが取り消されたりリセットされたりしたときに、プレイヤーはここへ送られます。
