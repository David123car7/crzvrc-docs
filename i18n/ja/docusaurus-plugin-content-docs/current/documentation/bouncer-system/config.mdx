# 設定

`SS_Config` クラスは、Bouncer System のコアとなる設定ファイルとして機能します。プレイヤーの収容数や、システムのロジック全体で使用されるさまざまなセキュリティ階層レベルを定義するグローバル定数を保持します。

システムが追跡できるプレイヤーの最大数を増やす必要がある場合や、独自のカスタム Udon スクリプトでセキュリティレベルを参照する必要がある場合は、これらの値がここで定義されています。

*   **`PLAYER_CAPACITY`**: Bouncer System が追跡および同期できるプレイヤーの最大数を定義します。デフォルトは `5` です。**注意:** VRChat ワールドが 5 人を超えるプレイヤーを許可している場合、エラーを防ぐために、この整数をワールドの最大インスタンス収容数に合わせて増やす必要があります。
*   **`SECURITY_LEVEL_NONE`** (`-1`): デフォルトの状態。セキュリティ権限を持たない標準的なプレイヤーを表します。
*   **`SECURITY_LEVEL_TEMPORARY`** (`0`): アクティブなインスタンス中に一時的なセキュリティアクセスを付与されたプレイヤーを表します（例: 別のセキュリティメンバーによって昇格された通常のプレイヤー）。
*   **`SECURITY_LEVEL_PERMANENT`** (`1`): 高レベルの永続的なセキュリティアクセスを持つプレイヤーを表します（インスタンスオーナーや、Inspector にハードコードされた、またはオンライン URL から取得された名前を持つユーザーなど）。
