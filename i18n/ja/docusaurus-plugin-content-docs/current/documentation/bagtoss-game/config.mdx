# 設定

Pastebin を使用して、独自の文章リストをゲームに簡単に読み込むことができます。これにより、VRChat ワールドを再アップロードすることなく、インターネット経由でゲームのテキストを動的に更新できます！

これを設定するには、シーンのヒエラルキーで **BagTossGame** GameObject を選択し、Inspector で `BS_GameManagement` スクリプトを見つけます。

*   **リストを作成する:** Pastebin にアクセスし、使用したいすべての文章を含む新しいペーストを作成します。各文章は改行して 1 行ずつ配置してください。
*   **Raw リンクを取得する:** 保存したら、Pastebin ページの **Raw** ボタンをクリックします。
*   **URL をコピーする:** ブラウザのアドレスバーから URL をコピーします（`https://pastebin.com/raw/...` のような形式になります）。
*   **Unity にリンクする:** この raw URL を `BS_GameManagement` スクリプトの **Sentences List Url** フィールドに貼り付けます。

文章はライブリンクから取得されるため、新しい更新がないか Pastebin をどのくらいの頻度で確認するかをゲームに指定できます。

*   **Reload Delay:** `BS_GameManagement` スクリプトで **Reload Delay** フィールドを見つけます。
*   **時間を設定する:** 秒単位で値を入力します。たとえば `600` と入力すると、システムは 10 分ごとに文章リストを再取得します。
