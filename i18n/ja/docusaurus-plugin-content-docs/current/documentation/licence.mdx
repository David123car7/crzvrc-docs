# ライセンスマネージャー

シームレスで安全、かつ簡単に更新できる体験を実現するため、私のアセットではカスタムのライセンスマネージャーシステムを使用しています。

私のストア（Jinxxy または Booth）でアセットを購入すると、最初はアセット本体ではなくライセンスマネージャーのツールをダウンロードします。このツールを使用すると、アカウントを同期し、購入内容を確認し、Unity 内で直接アセットをダウンロードできます。

以下は、セットアップ方法の完全なステップバイステップガイドです。

---

## 1. ライセンスマネージャーを開く

ストアからライセンスマネージャーをダウンロードし、`.unitypackage` を Unity プロジェクトにインポートした後:

1. Unity の上部メニューバーを確認します。
2. **CrZVRC** > **License Manager** をクリックします。
3. ライセンスマネージャーのウィンドウが開き、Unity のレイアウトにドッキングされます。

---

## 2. アカウントの同期（初回のみのセットアップ）

アセットをアクティベートしてダウンロードする前に、VRChat アカウントを私のプラットフォームと同期する必要があります。**この作業は一度だけ行えば済みます。**

:::caution 
Unity プロジェクト内で **VRChat SDK** のコントロールパネルにログインしている**必要があります**。ライセンスマネージャーは、SDK から直接、安全かつ自動的にあなたの VRChat User ID を抽出します。
:::

**同期の手順:**

1. **VRChat ID を確認する:** ライセンスマネージャーが自動的にあなたの VRChat User ID を取得して表示します。
2. **メールアドレスを入力する:** 使用したいメールアドレスを所定のテキストフィールドに入力します。
3. **コードをリクエストする:** **Send Code** ボタンをクリックします。
4. **認証する:** メールの受信トレイで認証コードを確認します。このコードをライセンスマネージャーに入力し、**Verify code** をクリックします。

---

## 3. アセットの登録とダウンロード

### ライセンスキーの取得

*   **Jinxxy での購入:** ライセンスキーは、購入時にストアページまたは領収書に自動的に提供されます。
*   **Booth での購入:** Booth はライセンスキーを自動的に生成しません。キーを取得するには、[Discord サーバー](https://discord.com/invite/3W7h3Bp3mH)に参加し、サポートチケットを開いて購入の証明を提出してください。私が手動でライセンスキーを生成してお送りします。

### アセットのアクティベート

1. **ライセンスを登録する:** 取得したライセンスキーをライセンスマネージャーに入力して送信します。
2. **アクティベート済み製品を表示する:** 登録が完了すると、製品はすぐにライセンスマネージャーのウィンドウ内の **Activated Products** リストに表示されます。
3. **ダウンロードとインポート:** アセットの横にあるダウンロードボタンをクリックします。ライセンスマネージャーはアセットをプロジェクトに直接ダウンロードし、`.unitypackage` のインポートを求める標準の Unity ダイアログを自動的に開きます。

これですべて完了です！ アセットはプロジェクトに追加され、使用できる状態になりました。

---


:::danger
ライセンスは、同期プロセス中に使用した **VRChat User ID** に永続的に紐付けられることにご注意ください。

この直接的な紐付けのため、**何らかの理由で VRChat アカウントへのアクセスを失った場合（ログイン情報の紛失、アカウントの削除、BAN など）、購入したアセットへのアクセスも失われます。**

ライセンスは一度登録されると別の VRChat アカウントへ移行できないため、VRChat アカウントを安全に保つようにしてください。
:::
