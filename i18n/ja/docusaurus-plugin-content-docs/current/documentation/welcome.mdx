## 互換性と要件

私のすべてのアセットは積極的にメンテナンスされており、**最新の VRChat SDK** および VRChat がサポートする**最新の Unity バージョン**で動作することが保証されています。
非推奨のコードや古いシステムに悩まされることがないと分かった上で、安心してワールドを制作できます。VRChat が要件を更新するのに合わせて、これらのアセットとドキュメントも更新されます。
