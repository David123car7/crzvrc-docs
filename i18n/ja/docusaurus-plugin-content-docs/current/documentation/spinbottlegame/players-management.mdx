# プレイヤー管理

:::info[Normal バージョン専用]
このページは **Normal** バージョン（`SB_SpinBottleGame`）にのみ適用されます。**Lite** バージョン（`SBL_SpinBottleGame`）には参加のステップもプレイヤーパネルもなく、誰でもすぐにボトルを回せます。
:::

Normal バージョンでは、プレイヤーは回す前に **参加** する必要があります。ゲームは同期されたプレイヤーパネル上で最大 `PLAYER_CAPACITY` 人のプレイヤーを追跡し、最初に参加したプレイヤーが、その場に留まっている間 **オーナー** になります。

---

## プレイヤー数の上限

`PLAYER_CAPACITY`（デフォルト `8`）は、同時にゲームへ参加できるプレイヤー数を制限します。この定数が実際のプレイヤー数の上限として機能するのは、このバージョンだけです。Lite には参加のステップがないためです。この定数は共有の `SB_Config` スクリプトにあります。変更方法は、Configuration ページの [テーブルサイズ](./config.mdx) を参照してください。

---

## 仕組み（`SB_PlayersManagement`）

*   参加したプレイヤーは同期されたリストで追跡されます。**オーナー** は最初のスロットを占めるプレイヤー、つまり通常は最初に参加したプレイヤーです。オーナーが退出すると、次に並んでいるプレイヤーが自動的にオーナーに昇格します。
*   ゲームが **ロック** されている間、新しいプレイヤーは参加できません。
*   最後のプレイヤーが退出すると、ゲームは自動的にリセットされ（着地した文章と最後にプレイしたプレイヤーがクリアされ）、次のグループを迎える準備が整います。

---

## ボタン（`SB_UIInteraction`）

以下の公開メソッドを、UI ボタンの `OnClick` イベントに配線してください。

| メソッド | 説明 |
| :--- | :--- |
| `EnterGame()` | ローカルプレイヤーをゲームに追加します。**参加** ボタンに配線します。 |
| `ExitGame()` | ローカルプレイヤーをゲームから削除します。そのプレイヤーが最後の 1 人だった場合、ゲームをリセットします。**退出** ボタンに配線します。 |
| `ToggleLockGame()` | ロック状態を反転します。**オーナー専用** — オーナー以外のプレイヤーが呼び出しても何も起こりません。**ロック / ロック解除** ボタンに配線します。 |
| `ChangeText()` | テーブル上のすべての文章を再抽選します。**オーナー専用**。**再抽選** ボタンに配線します。 |
| `ResetGame()` | ゲームを空の状態（プレイヤーなし、着地した文章なし）に戻します。**オーナー専用**。**リセット** ボタンに配線します。 |

---

## UI のスタイル

プレイヤーパネル、プレイヤーカード、ゲームメニューパネルはすべて、`SB_ConfigUI` という 1 つの共有カラーテーマでスタイル設定されています。詳しくは [UI 設定](./uiconfiguration.mdx) ページを参照してください。
