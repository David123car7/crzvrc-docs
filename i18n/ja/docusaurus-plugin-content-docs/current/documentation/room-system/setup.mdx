# セットアップ

VRChat ワールドで Room System とその必要な依存関係をセットアップするのは、素早く簡単です。すべてを正しく動作させるために、次の手順を注意深く実行してください。

---

1. **パッケージをインポートする:** **Room System** パッケージと **Notification System** パッケージの両方を、プロジェクトに正常にダウンロードしてインポートしていることを確認してください。*（注: Notification System は、インターホンの呼び出しとアクセス拒否アラートに必要な、必須の依存関係です。）*

2. **Notification System を配置する:** プロジェクトファイル内で **Notification System** プレハブを見つけ、そのインスタンスを 1 つだけアクティブなシーンのヒエラルキーにドラッグします。

3. **ルームを配置する:** プロジェクトファイル内で **Room System** プレハブを見つけます。このプレハブをシーンのヒエラルキーにドラッグ＆ドロップします。作成したいルーム*ごと*にこれを行う必要があります（例: ワールドに 5 つの独立したルームがある場合、プレハブをシーンに 5 回ドラッグし、それぞれ適切に配置します）。

4. **Rooms Management を追加する:** 次に、**Rooms Management** プレハブを見つけ、そのインスタンスを 1 つだけシーンにドラッグします。このプレハブは、先ほど配置したすべての個別のルームを調整する頭脳として機能します。

5. **Notification System とルームをマネージャーにリンクする:** シーンのヒエラルキーで **Rooms Management** プレハブを選択します。Unity の Inspector で、その Udon スクリプトを探します:
   * **Notification System** プレハブを Notification System の参照スロットにドラッグ＆ドロップします。
   * シーン内のすべての **Room System** プレハブを rooms 配列にドラッグ＆ドロップします。
   
> 💡 **重要:** ルームは、論理的で連続した順序で配列に追加してください（たとえば、廊下の最初のルームから始めて、最後のルームで終わるようにします）。システムは、このリストに配置された正確な順序に基づいて、ルーム番号を自動的に割り当てます。

6. **CrZVRC ツールを開く:** Unity エディターの一番上のツールバーを見ます。**CrZVRC** をクリックし、ドロップダウンメニューから **Room System** を選択します。

7. **Render Texture を生成する:** カスタムエディターウィンドウが開きます。**Generate Render Textures** ボタンをクリックするだけです。

8. **確認を待つ:** ツールが UI に必要な render texture を自動的に設定します。完了すると、セットアップが完了したことを通知する小さなポップアップウィンドウが表示されます！
