# 設定

Room System のコア設定は、`RS_Config` スクリプト内で管理されます。このファイルには、ルーム、UI キュー、およびワールド自体の収容数と上限を定義するグローバル定数が保存されています。

ルームに許可されるプレイヤーの最大数を調整する必要がある場合や、VRChat インスタンスの設定に合わせてワールドの収容数上限を増やす必要がある場合は、`RS_Config` スクリプト内でこれらの値を直接変更します。

---

## 定数の概要

*   **`WORLD_MAX_CAPACITY`**（デフォルト: `12`）: VRChat ワールドが収容できるプレイヤーの最大数を定義します。

    **重要:** クライアント間の同期エラーを防ぐため、この数値がワールドの最大インスタンス収容数（追加収容分を含む）と一致していることを確認する必要があります。
*   **`ROOM_MAX_CAPACITY`**（デフォルト: `8`）: 任意の時点で 1 つのルームに対して追跡、招待、またはアクセス許可できるプレイヤーの最大数。
*   **`ROOM_MAX_NOTIFICATIONS`**（デフォルト: `6`）: ルームのキューが新しいものの受け付けを停止するまでに保持できる、インターホンの呼び出しの最大数。
*   **`ROOM_SETTINGS`**（デフォルト: `2`）: ルームシステムの状態によって追跡される、カスタムの切り替え可能な設定の数。ルームの UI にさらに多くのカスタムトグル（ライト、ミラー、メディアプレーヤーの調整など）を追加する予定がある場合は、これを増やしてください。

---

## ルームの位置設定

プレイヤーがルームに入退室する際に正しくテレポートおよび管理されるようにするには、ルームの親 GameObject でテレポートのターゲットを設定する必要があります。

ヒエラルキーでメインの **RoomSystem** GameObject を選択し、Inspector で次の 2 つの Transform を調整します:
*   **`insideRoomPositiom`**: この Transform を、プレイヤーを出現させたいルーム内の正確な位置に移動します。
*   **`outsideRoomPositiom`**: この Transform を、ルームの外（廊下やロビーなど）の位置に移動します。権限のないプレイヤーがキックされたり、アクセスチェックに失敗したりした場合、ここへテレポートされます。

---

## サウンドエフェクト

ワールドの雰囲気により合うようにデフォルトのオーディオクリップを差し替えたい場合は、それぞれの GameObject でサウンドエフェクトを直接変更できます:
*   **インターホンのサウンド:** ルームのヒエラルキーで **`_intercom`** GameObject を見つけて選択し、呼び出し音や通知音を変更します。
*   **カメラのサウンド:** **`_selfieCamera`** GameObject を見つけて選択し、ルームのセキュリティカメラによってトリガーされるサウンドエフェクトを調整します。

### 通知アラートのカスタマイズ

これらのアラートの外観とテキストは、**RoomsManagement** GameObject 上で直接、完全にカスタマイズできます。Inspector で `RS_NotificationConfig` スクリプトを探し、次の設定を変更します:

#### Deny User Notification
このアラートは、ルームオーナーがインターホンのリクエストを明示的に拒否したときに、プレイヤーへ送信されます。
*   **Deny User Text:** アラートのメインヘッダーテキスト（デフォルトは `NOT ACCEPTED`）。
*   **Deny User Text Color:** メインヘッダーテキストの色。
*   **Deny User Sub Text Color:** サブテキスト（通常はルームオーナーの名前が表示される）の色。
*   **Deny User Sprite:** メッセージの横に表示されるアイコン。
*   **Deny User Sprite Color:** アイコンに適用される色合い。

#### Intercom Ring Notification
このアラートは、誰かが外部からルームを呼び出したときに、ルームオーナーへ送信されます。
*   **Intercom Ring Text:** アラートのメインヘッダーテキスト（デフォルトは `INTERCOM RING`）。
*   **Intercom Ring Text Color:** メインヘッダーテキストの色。
*   **Intercom Ring Sub Text Color:** サブテキスト（通常は呼び出した人の名前が表示される）の色。
*   **Intercom Ring Sprite:** メッセージの横に表示されるアイコン。
*   **Intercom Ring Sprite Color:** アイコンに適用される色合い。

> ⚠️ **重要な音声に関する注意:**  
> Notification System プレハブの **Sound Effects** オプションを無効にすることを推奨します。有効なままにすると、デフォルトの通知アラート音が Room System のカスタムインターホン呼び出し音と同時に再生され、音が重なってしまいます。  
> 
> *他のシステムでサウンドエフェクトが必要ですか？* ワールドが他のアセットで通知システムを使用しており、音声アラートが必要な場合は、2 つ目の Notification System プレハブをヒエラルキーに配置し、サウンドエフェクトを無効にした状態で Room System 専用に割り当ててください。
