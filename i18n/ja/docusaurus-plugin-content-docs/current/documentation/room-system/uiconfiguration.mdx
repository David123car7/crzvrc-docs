# UI の設定

Room System には高度にカスタマイズ可能なユーザーインターフェースが含まれており、システムのメニューやパネルを、ワールド固有の雰囲気にシームレスに溶け込ませることができます。

**Rooms Management** を選択することで、コードを編集したり、深い UI ヒエラルキーを掘り下げたりすることなく、色、背景、ページタイトルを簡単に調整できます。

---

## テーマと背景

これらの設定は、Room System のインターフェースの基本的なルックアンドフィールを制御します。

*   **Primary Color:** UI 全体で使用されるメインのアクセントカラーを設定します（デフォルト設定ではシアンで表示されます）。
*   **Background Color:** UI パネルのベースカラーを決定します。
*   **Background Image:** ルームのインターフェースの背景として機能するカスタム画像を割り当てることができます。

---

## ドアの状態の色

ロック状態とロック解除状態に関連付けられた色をカスタマイズすることで、ルームが開いているか制限されているかを視覚的に伝えることができます。

### ルームがロックされているときの色
*   **Is Locked Primary Color:** ルームがロックされているときに表示されるメインカラー（デフォルトは赤）。
*   **Is Locked Secondary Color:** ロック状態のセカンダリアクセントカラー（こちらもデフォルトは赤）。

### ルームがロック解除されているときの色
*   **Is Unlocked Primary Color:** ルームが開いていてアクセス可能なときに表示されるメインカラー（デフォルトは緑）。
*   **Is Unlocked Secondary:** ロック解除状態のセカンダリアクセントカラー（こちらもデフォルトは緑）。

---

## ルーム設定のタイトル

ワールドのテーマに合うように Room System UI のさまざまなタブの名称を変更したい場合（たとえば "Room" を "Apartment" に、"Intercom" を "Notifications" に変更するなど）、ここでページヘッダーの名前を簡単に変更できます。

*   **Main Page Text:** メインのステータスページのタイトル。デフォルトは `Overview`。
*   **Notifications Page Text:** 通知エリアのタイトル。デフォルトは `Intercom Queue`。
*   **Intercom Page Text:** アクティブなインターホン画面のタイトル。デフォルトは `Intercom Feed`。
*   **Invite Page Text:** オーナーがアクセスを管理するメニューのタイトル。デフォルトは `Invite Players`。
*   **Settings Page Text:** ルームの設定メニューのタイトル。デフォルトは `Room Settings`。
