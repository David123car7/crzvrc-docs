# プライバシーポリシー

**最終更新日: 2026年8月25日**

このプライバシーポリシーは、あなたが当社の VRChat アセット、システム、および関連サービスを購入、アクティベート、または使用する際に、CrZVRC が個人データをどのように収集し使用するかを説明します。

## 管理者と連絡先

あなたの個人データについて責任を負う管理者は、ポルトガルを拠点として運営される **CrZVRC** です。

**プライバシー用メールアドレス:** **crzvrc@gmail.com**  

技術サポートのご依頼には、当社の公式 [Discord サポートサーバー](https://discord.com/invite/3W7h3Bp3mH) もご利用いただけます。データ保護に関するご依頼には、上記のビジネス連絡先をご利用ください。

## 年齢制限

CrZVRC の製品、システム、およびアセットは、**18 歳以上**のユーザーのみを対象としています。アセットを購入、ダウンロード、または認証することにより、あなたはこの要件を満たしていることを確認したものとみなされます。当社は、児童から個人データを故意に収集することはありません。

## 当社が収集するデータ

安全な体験を提供し、無許可の配布を防止するため、当社のカスタム認証 API は、あなたがライセンスをアクティベートする際に特定の情報を収集します。あなたが Unity 経由で当社のアセットをインポートして認証する際、当社は以下のデータを安全に記録します:

- **メールアドレス:** 元の購入に関連付けられたメールアドレス。
- **VRChat User ID:** セットアップ時にあなたが当社に提供する、特定の VRChat アカウント ID。
- **ライセンスキーのハッシュ:** あなたのライセンスキーの SHA-256 ハッシュ。当社は、平文のライセンスキーではなく、このハッシュを保存します。
- **ライセンスの種類:** あなたのライセンスの階層（例: Personal または Commercial）。
- **ストアの提供元:** 購入が行われたプラットフォーム（例: Jinxxy または Booth）。
- **製品 ID:** あなたがアクティベートしている特定のアセットの内部識別子。
- **アクティベーションのステータス:** ライセンスの現在の有効、取り消し済み、または期限切れの状態。
- **アクティベーションのタイムスタンプ:** 認証リクエストが作成された正確な日時。

## データの利用

この情報は、あなたの購入を検証し、正しいアセットファイルをあなたの Unity プロジェクトに提供し、正確な技術サポートを提供するためにのみ収集されます。当社は、このデータを内部のセキュリティおよびライセンス管理のためにのみ厳密に使用し、あなたの情報を第三者に販売することはありません。

## あなたのデータを処理するサービス

以下のサービスは、あなたのライセンスの提供および管理の一環としてデータを処理します:

- **Jinxxy:** ライセンスのアクティベーションに使用される購入情報およびライセンス情報。
- **CrZVRC データベース:** 当社のデータベースは、このポリシーに記載されているライセンスおよびアクティベーションのデータを保存します。
- **CrZVRC ライセンス管理 API:** 当社の API は、ライセンスのアクティベーションとステータスを検証および管理します。

## データの保持と削除

当社は、ライセンス管理、セキュリティ、およびサポートの目的で、ライセンス、アクティベーション、および関連するアカウントデータを無期限に保持します。

**crzvrc@gmail.com** までご連絡いただくことで、個人データの削除をリクエストできます。ライセンス管理はこのデータに依存しているため、削除リクエストが完了すると、あなたのアカウントに関連付けられたすべてのライセンスが永久に取り消され、それらのライセンスが再びアクティベートされることはなくなります。法的義務を遵守するため、または不正行為やライセンスの不正使用から保護するために必要な場合、当社は限定的な情報を保持することがあります。

## あなたの権利

適用される法律に従い、あなたは自身の個人データへのアクセス、訂正、削除、または処理の制限をリクエストできます。また、データポータビリティのリクエスト、正当な利益に基づく処理への異議申し立て、および同意に基づく処理の場合の同意の撤回も行えます。

これらの権利を行使するには、上記に記載されたプライバシー連絡先を使用して当社にご連絡ください。あなたはまた、ポルトガルのデータ保護機関である **Comissão Nacional de Proteção de Dados (CNPD)**、またはお住まいの地域の監督機関に苦情を申し立てる権利も有しています。

## コミュニケーションと更新

VRChat アカウントを認証し、メールアドレスを提供することにより、あなたは CrZVRC からのコミュニケーションを受け取ることに同意したものとみなされます。これには、重要な製品の更新およびセキュリティパッチが含まれます。

当社は、個人データを保護するために設計された、合理的な技術的および組織的措置を講じています。伝送または保存のいかなる方法も完全に安全ではなく、当社は絶対的なセキュリティを保証することはできません。

当社は、このプライバシーポリシーを随時更新することがあります。更新版はこのページに掲載し、「最終更新日」の日付を改訂します。法律で求められる場合、当社は重要な変更について追加の通知を行います。
